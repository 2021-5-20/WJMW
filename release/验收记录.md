| 检查 | 实测结果 |

| 身份与凭证 | 游客升级或绑定已有账号后保留原席位。换设备登录接管原座。另一浏览器重置密码后，原浏览器登录会话、在线牌桌控制和未消费的入座凭据失效。 |

| 写入失败与托管 | 人为使逐局结算写入失败，持久化状态和分数保持在上一版。恢复写入后，离线席位按原桌超时策略走完当前局，正常散桌，只产生一条结算记录。 |
| 数据库进程崩溃 | 在隔离数据库执行 immediate 停机，游戏服务因丢失数据库租约退出。两者恢复后，就绪检查通过。账号、玩家身份、三张牌桌的手牌与修订号，以及战绩的校验摘要与原值一致。 |

| HTTPS、发信与应用回退 | 本地 Caddy 内部 CA、生产模式的游戏服务和本地 SMTP 收件器跑通注册验证和 WSS 四人操作。会话 Cookie 含 Secure、HttpOnly、SameSite=Lax。用两份兼容发布副本演练坏配置启动失败后恢复旧程序，四个会话回桌时手牌和已确认的弃牌一致。 |
| 运维与隐私 | 已验证管理员才可查运营页，查询留下审计记录；战绩翻页保持玩家归属，普通请求看不到其他玩家的暗手或未摸牌墙。 |
