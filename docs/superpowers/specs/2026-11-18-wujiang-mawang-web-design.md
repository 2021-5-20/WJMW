# 《吴江麻王》浏览器首版设计

此文记录早期试玩版的设计与待核对规则。正式版账号、持久化、运行方式及新版桌规见[项目说明](../../../README.md)。新桌使用 `wj-2`，自风随庄轮转，三财神可自摸直接胡，流局保留连翻次数。

## 首版体验

四位玩家用手机或电脑浏览器打开同一个邀请链接，输入昵称入座。房主在四人到齐后开局。玩家打完一局后能查看计台明细，再准备下一局。房间内累计积分，并在开局时展示骰子、财神及翻倍状态。

首版提供好友房、邀请链接、四人对局和短时断线重连。公开匹配、账号体系和历史战绩留到后续。手机优先适配横屏牌桌，竖屏可以入房和查结算，进入牌桌时提示横屏。电脑支持鼠标，手机支持触控。

牌桌采用原创的江南小茶馆卡通风。浅竹青桌面搭配奶白色圆角牌、软萌头像和简短动效。牌面保留容易辨认的万、筒、条和字牌图案，财神有独立标记。翻倍局显示倍率和连续局进度。结算逐条标出牌型、加台和倍率。

## 技术方案

- **采用 Phaser + TypeScript。** Phaser 负责牌桌渲染、牌面动效和点牌交互。建房、入房、状态提示和结算使用 HTML/CSS。Vite 负责浏览器构建。这条路线方便直接用链接跨设备试玩。
- **对比 Cocos Creator + TypeScript。** Cocos 的编辑器和微信小游戏构建流程适合微信首发。现在先验证浏览器体验，微信版本可复用独立规则模块、网络协议和美术素材，再做平台界面与接入适配。

服务端使用 Node.js + Colyseus 管理四人房、消息和重连。服务端掌握完整牌局并裁定洗牌、摸牌、碰杠胡、操作优先级和计分。客户端只接收公开状态、本人的手牌和当前可操作项。短时断线保留座位，重连后恢复该玩家的状态和私有手牌。出牌和响应超时由服务端执行确定的默认动作，使牌局可以继续。

麻将规则、房间协议和界面分别组织。纯 TypeScript 规则模块接收牌局状态与操作，返回新状态和结算结果。测试可以注入固定牌序和骰点，覆盖胡牌、抢杠优先级与跨局翻倍。首版房间由单个服务进程承载。

## 已确认的规则

| 项目 | 规则 |
| --- | --- |
| 碰碰胡、混一色 | 各 3 台 |
| 清一色、三财神 | 各 10 台 |
| 自风牌或金张成刻 | 对应刻子加 1 台。自风按玩家自己的座风判定 |
| 明杠、暗杠 | 明杠 1 台，暗杠 2 台 |
| 金张或自风牌成杠 | 明杠 2 台，暗杠 3 台 |
| 大吊车 | 加 1 台 |
| 三碰承包 | 取消 |
| 财神翻到风牌或金张 | 东南西北任一风牌或任一金张触发，本局台数乘 2 |
| 骰子掷出豹子 | 两颗骰子同点，本局台数乘 2 |
| 同一局同时触发两个条件 | 连续三局翻倍 |

## 首版沿用和暂定的规则

沿用同城游 2023 年玩法说明的四人、可碰可杠、不可吃、两台起胡、仅自摸或抢杠、绕搭与丢搭不能抢杠，以及一局一人胡。使用万筒条、风牌和中发白共 136 张，无花牌。两台门槛在整局倍率前判定。

骰点之和决定开牌风家，大点决定开牌墩数，小点决定财神位置。翻开的牌保留在牌墙中作为普通摸牌的终点，摸到该位置时流局。首版以固定牌墙与骰点验证开牌、翻财神和流局顺序，具体数墩方向作为实现细节。

其余计台参考同城游旧教程。底胡 1 台，无百搭、绕搭、丢搭、海底捞月和杠上开花各 1 台，抢杠 2 台，天胡和地胡各 10 台。绕搭按四组牌配齐、单留百搭作将来判定。丢搭按打掉最后一张百搭后以无百搭的牌胡来判定。

正式编码前需核对与本地桌规可能有出入的点。设计采用以下试玩口径，便于确认或修正。

- 金张暂按中、发、白。座风随入座位置固定，换庄时保留各席原来的座风。
- 三财神暂作为有效胡牌的 10 台牌型。清一色与混一色互斥，其余能同时成立的牌型和加台暂按相加。无百搭的加台与丢搭产生的同一份加台只计算一次。
- 暂以常规四组一对判断基本牌型，附加的三门齐、幺九字牌或刻子门槛等着本地口径确认。抢杠暂限碰后补杠。
- 连续翻倍从触发当局起算，含当局和之后两局，每局乘 2。流局计入进度。期间再同时触发两个条件时，从该局重新算三局。单独触发其中一个条件时按本局乘 2。
- 暂按自摸由其余三家各付本局结算台数，抢杠由补杠者付三家的份额。胡家接庄，流局庄家连庄。

参考 [同城游 2023 年玩法说明](https://m.tcy365.com/news/d27065.html) 和 [同城游 2018 年教程](https://tcy365.com/news/d8769.html)。

## 试玩验收

- 手机与电脑浏览器可进入同一房间，四个席位从开局打到结算，再进入下一局。
- 服务器拒绝越权、过时或无效操作。结算前别家的暗牌与未摸牌墙不会发给客户端。短时重连可以继续原对局。
- 固定牌例能复现两台起胡、碰杠、抢杠、大吊车及计台明细。骰点和财神的四种组合都能验算，三局翻倍能跨结算继续，结束后恢复正常结算。
